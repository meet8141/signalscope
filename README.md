# SignalScope - Model Training Results

This repository contains the results of the SignalScope MobileNetV2 training for Real vs Fake image classification. 

## Model Performance Stats

The following are the primary metrics and operating points from the model training:

### Primary Metric
*   **ROC-AUC**: 0.9690

### Classification
*   **Macro-F1**: 0.9068
*   **Accuracy**: 0.9071
*   **Precision**: 0.8821
*   **Recall**: 0.9234

### Operating Point
*   **Threshold**: 0.5452
*   **Specificity**: 0.8929
*   **False Positive Rate**: 0.1071

### Confusion Matrix
*   **TN**: 13541
*   **FP**: 1624
*   **FN**: 1009
*   **TP**: 12156

### Additional
*   **Average Precision**: 0.9633
